# Circle Storybooks

Circle Storybooks is an online application that uses generative AI to custom design and print board books for babies and toddlers.

## Getting started

* Run `mix setup` to install and set up dependencies
* Start the server with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Visit [`localhost:4000`](http://localhost:4000) in your browser.
